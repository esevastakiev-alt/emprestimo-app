# App instalável (PWA)

A mesma jornada de `demo/v2/jornada-v2.html`, empacotada como app: ícone na tela inicial, abre em tela cheia e
funciona sem internet depois da primeira abertura. Gerado por `python3 scripts/gerar-demo-offline.py`.

**Publicar:** qualquer hospedagem estática com HTTPS (GitHub Pages, Netlify, servidor do banco). Basta servir esta pasta.

**Instalar no celular:** abra o link.
- Android (Chrome): menu ⋮ → "Instalar app" ou "Adicionar à tela inicial".
- iPhone (Safari): botão Compartilhar → "Adicionar à Tela de Início".

Os dados são fictícios e ficam só no aparelho (API simulada no navegador, mesmas regras e campos da API Java).
